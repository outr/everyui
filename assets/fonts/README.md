# Bundled fonts

The faces youi's AnimationExample uses, as TrueType so both backends can load them
(the web through `@font-face`, the Roku through a SceneGraph `Font` node). Downloaded
from Google Fonts (`fonts.gstatic.com`, the same source youi loads at runtime) and
unwrapped from WOFF to TTF without changing any table.
